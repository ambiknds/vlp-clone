## Decisions & Assumptions
1. **CLI Installation**: Install the Clerk CLI globally via `npm install -g clerk` (if not present).
2. **Authentication**: Run `clerk auth login` to ensure authenticated session with Clerk.
3. **Initialization**: Initialize Clerk in this project targeting app `app_3JrUoWP8UhPtAKn9CP0mmwcn2GP`:
   `clerk init --app app_3JrUoWP8UhPtAKn9CP0mmwcn2GP`
4. **Proxy / Middleware Matcher**: Ensure `proxy.ts` (or `middleware.ts` if generated by `clerk init`) is configured with `clerkMiddleware()` and `config.matcher` includes Clerk's auto-proxy path:
   ```ts
   '/(api|trpc)(.*)',
   '/__clerk/:path*',
   ```
   If `clerk init` outputs `middleware.ts`, verify or adapt for Next.js 16 `proxy.ts` / `middleware.ts` compatibility.
5. **Provider Placement**: Wrap application children with `<ClerkProvider>` inside `<body>` in `app/layout.tsx` (not wrapping `<html>`).
6. **Auth Controls in HeaderNav**:
   - Integrate Clerk components from `@clerk/nextjs`: `SignInButton`, `SignUpButton`, `Show`, `UserButton`.
   - When signed out: show `SignInButton` and `SignUpButton` wrapped in `<Show when="signed-out">`.
   - When signed in: show `<UserButton />` wrapped in `<Show when="signed-in">`.
7. **Verification**: Run `clerk doctor` and Next.js verification checks (`npm run lint`, `npx tsc --noEmit`, `npm run build`).
